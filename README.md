# El Almacén Café

Sitio web de El Almacén Café.

## Stack

- [Astro](https://astro.build)
- [Tailwind CSS](https://tailwindcss.com)
- [daisyUI](https://daisyui.com)

## Estructura

```
front/   Frontend en Astro
back/    Reservado para el backend (aún sin uso)
```

## Desarrollo

```bash
cd front
npm install
npm run dev
```

El servidor queda en http://localhost:4321.
